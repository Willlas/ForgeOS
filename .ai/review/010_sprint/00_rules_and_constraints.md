# 00 — Rules and Constraints (Global)

## Purpose
Define the rules that apply to every phase of this architecture review.

## Rules

- Read ONE file at a time.
- Before reading a file, verify it exists.
- Use PowerShell only.
- Do NOT perform repository-wide searches.
- Read only the minimum number of files required.
- Never assume architecture.
- Every conclusion must be supported by evidence.

## Negative Constraints (What NOT to do)

- Do NOT modify the repository.
- Do NOT implement anything.
- Do NOT commit.
- Do NOT update ROADMAP.md.
- Do NOT update PROJECT_STATE.md.
- This is an architecture audit only.

## Output Expectations

For every file inspected:
- Record the file path.
- Record which lines were relevant.
- Record the evidence found.
