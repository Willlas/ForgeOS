# Sprint 011 Review

This folder records evidence for External Workspace Tool Access.

## Review Questions
- Is access denied without an explicit grant?
- Are reads confined to the granted canonical root?
- Are commands allowlisted and bounded?
- Are mutations approved, hashed and recoverable?
- Are IPC sessions isolated and audited?

The review SHALL use executable tests and CLI smoke tests. It SHALL not grant permissions or modify an external project as part of the review.
