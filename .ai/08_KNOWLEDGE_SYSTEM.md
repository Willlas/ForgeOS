# Purpose

The Knowledge System stores engineering knowledge.

It is not conversation history.

It is not chat memory.

It is not context.

Knowledge represents durable engineering understanding.

Knowledge survives sessions.

Knowledge survives models.

Knowledge survives contributors.

The repository itself becomes progressively more intelligent.

---

# Philosophy

Memory answers:

"What happened?"

Knowledge answers:

"What have we learned?"

These are fundamentally different questions.

Memory is temporal.

Knowledge is structural.
